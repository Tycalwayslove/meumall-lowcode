# TASK-2026-0731-058 编辑器物料详情预览

## 状态

verified

## 目标

增强 Vue3 编辑器 playground 的物料库，让运营在添加物料前可以查看物料详情、默认 H5 预览、配置字段、事件和数据槽。

## 背景

当前编辑器已有物料搜索、分类过滤、收藏、最近使用和一键添加能力，但运营在点击添加前只能看到物料名称、分类和组件名。随着基础物料和营销物料变多，运营需要先理解物料能做什么、长什么样、有哪些可配置项，才能更安心地搭建页面。

## 涉及包或系统

- `apps/editor-playground`
- `scripts/browser-smoke.mjs`
- `.ai-workspace/tasks`
- `.ai`

## 范围

- 物料卡片新增独立详情入口。
- 详情弹窗展示物料标题、分类、组件名、版本和平台。
- 详情弹窗使用现有 Vue H5 renderer 渲染该物料默认 H5 预览。
- 详情弹窗展示 propsSchema 字段摘要。
- 详情弹窗展示事件和数据源槽位摘要。
- 详情弹窗支持一键添加当前物料到画布。
- Browser smoke 覆盖物料详情、默认预览和一键添加。
- 更新 AI 项目状态和任务记录。

## 不包含

- 不新增 Material Manifest 字段。
- 不新增物料组件。
- 不修改 renderer API。
- 不新增 Java 物料市场接口。
- 不修改 npm 公开 API。

- Vue H5 renderer 继续负责按 schema 渲染物料预览。

- 详情弹窗支持一键添加当前物料到画布，并记录最近使用。
