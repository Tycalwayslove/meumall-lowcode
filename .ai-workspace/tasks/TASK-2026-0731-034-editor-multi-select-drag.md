# TASK-2026-0731-034-editor-multi-select-drag

## 状态

verified

## 目标

增强 Vue3 编辑器 playground 的结构编辑效率，支持同父级节点多选并成组拖拽移动，让运营可以一次移动多个连续或非连续页面区块。

## 背景

当前编辑器已经支持单节点拖拽、触屏拖拽、画布吸附线和结构树排序。运营搭建活动页时，经常需要把多个同层楼层、商品区块或营销模块一起前移、后移或移入容器。只支持单节点移动会让调整大型活动页顺序变得繁琐。

本任务在不改变 schema、renderer、material manifest 和 `@meumall/lowcode-editor` 公开 API 的前提下，在 `apps/editor-playground` 增加同父级多选和成组拖拽编排。

## 涉及包或系统

- `apps/editor-playground`
- `.ai-workspace`
- `.ai`

## 范围

包含：

- 结构树支持多选节点。
- 普通点击仍保持单选；勾选/Meta/Ctrl/Shift 点击可加入或移除多选。
- 多选节点同属一个父节点时，拖拽其中任意一个已选节点可成组移动。
- 成组移动支持移动到同父级目标前/后、移动进容器末尾或移动到页面末尾。
- 画布拖拽和结构树拖拽复用同一成组移动逻辑。
- 多选状态在模板切换、JSON 应用、版本载入、删除等场景下自动收敛。
- 更新任务、项目状态、上下文、TODO 和验证记录。

不包含：

- 不实现跨父级多组选区的一次性复杂重排。
- 不实现框选、拖拽选择区域或键盘多选快捷键。
- 不修改 schema、renderer、material manifest 或 editor 包公开 API。
- 不接入真实素材、商品、优惠券、门店或达人中心。
