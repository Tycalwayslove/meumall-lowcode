# TASK-2026-0731-056 编辑器新建页面向导

## 状态

verified

## 目标

为 Vue3 编辑器 playground 增加新建页面向导，让运营可以从空白页或已有模板快速开始编辑，并在替换当前草稿前获得明确确认。

## 背景

当前编辑器已具备模板库、模板摘要、模板 H5 预览和物料编辑能力，但新建页面入口仍偏工具化。运营打开编辑器后，需要更明确地选择“空白搭建”或“套用模板”，否则很容易直接在现有示例页上改动，降低实操信心。

## 涉及包或系统

- `apps/editor-playground`
- `scripts/browser-smoke.mjs`
- `.ai-workspace/tasks`
- `.ai`

## 范围

- 顶部工具栏新增新建页面入口。
- 新建页面向导展示空白页起点和模板起点。
- 空白页起点会创建可编辑的空白 H5 页面。
- 模板起点复用已有 Template Library Client 和应用模板逻辑。
- 当前草稿有未保存变更时继续二次确认，避免误替换。
- Browser smoke 覆盖打开向导、空白页创建和模板起点应用。
- 更新 AI 项目状态和任务记录。

## 不包含

- 不新增 Java 模板市场 API。
- 不修改 Page Schema 字段。
- 不新增 npm 公开 API。
- 不实现多步骤发布审批。
- 不新增模板缩略图上传能力。

## 责任边界

- 编辑器 playground 负责提供新建页面向导、空白页初始化和模板入口。
- Template Library Client 继续负责模板查询和详情读取。
- H5 runtime 继续只消费最终 schema，不感知向导 UI。

1. 新增向导显示状态、空白页 schema 工厂和新建页面操作。

## 实现结果

- 顶部工具栏新增“新建”入口，并可通过快捷命令搜索“新建页面”打开同一向导。
- 新建页面向导提供空白 H5 页面起点和模板起点。
- 空白页起点使用 `createLowcodePageSchema` 生成本地 H5 草稿，创建后画布为空、状态为未保存，并可继续添加物料。
- 模板起点复用现有 Template Library Client 和 `applyTemplate`，应用成功后关闭向导。
- 当前草稿未保存时，空白页和模板替换都会继续要求二次确认。
- Browser smoke 已覆盖向导打开、空白页创建和模板起点应用。
