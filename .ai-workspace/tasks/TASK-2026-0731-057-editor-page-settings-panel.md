# TASK-2026-0731-057 编辑器页面设置面板

## 状态

verified

## 目标

增强 Vue3 编辑器 playground 的页面设置能力，让运营可以直接配置页面标题、描述、页面类型、发布环境、背景色、安全区和画布最大宽度。

## 背景

当前编辑器已经具备新建页面向导、模板选择、物料编辑、H5 预览和发布检查，但右侧页面面板仍偏基础，主要只提供标题、Page ID、状态和环境。运营要把页面真正交给 H5 渲染前，需要在可视化界面里完成更多页面级配置，减少切换到源码 JSON 的频率。

## 涉及包或系统

- `apps/editor-playground`
- `scripts/browser-smoke.mjs`
- `.ai-workspace/tasks`
- `.ai`

## 范围

- 页面面板展示并编辑页面描述。
- 页面面板展示并编辑页面类型。
- 页面面板展示并编辑布局背景色。
- 页面面板展示并编辑安全区开关。
- 页面面板展示并编辑 H5 最大宽度。
- 页面面板保留 Page ID、状态和发布环境。
- Browser smoke 覆盖页面设置写入 schema。
- 更新 AI 项目状态和任务记录。

## 不包含

- 不新增 Page Schema 字段。
- 不修改 renderer API。
- 不新增 Java 配置平台接口。
- 不实现服务端页面元数据保存。
- 不修改 npm 公开 API。

## 责任边界

- 编辑器 playground 负责提供已有 Page Schema 字段的可视化编辑 UI。
- schema 包继续定义字段类型和校验规则。
- H5 renderer 继续按 schema.layout 渲染页面，不感知编辑器 UI。

## 实现计划

1. 增加页面描述、页面类型、布局背景色、安全区和最大宽度更新方法。
2. 扩展右侧页面设置面板，提供输入框、下拉、颜色选择、快捷色板、开关和数字输入。
3. 补充 browser smoke，验证页面设置能同步到 UI 和源码 schema。
4. 更新 AI 状态、TODO 和任务验证记录。

## 实现结果
