# TASK-2026-0731-054 编辑器模板卡片摘要

## 状态

verified

## 目标

增强 Vue3 编辑器页面模板库的信息密度，让运营在应用模板前能快速判断模板适用场景、节点规模、数据源和动作情况。

## 背景

当前左侧模板库支持搜索和分类过滤，但模板卡片主要展示标题、分类和描述。随着模板数量增加，运营需要更明确的选择依据，例如模板包含多少节点、是否依赖数据源、是否配置动作、适合什么标签场景。

## 涉及包或系统

- `apps/editor-playground`
- `.ai-workspace/tasks`
- `.ai`

## 范围

- 左侧模板卡片展示标签、版本、节点数、数据源数和动作数摘要。
- 模板卡片保留一键应用能力。
- 模板搜索继续可匹配标题、描述、分类和标签。
- Browser smoke 覆盖模板标签和摘要展示。
- 更新 AI 项目状态和任务记录。

## 不包含

- 不新增模板市场 API。
- 不修改 Template Library Client 公开契约。
- 不新增模板缩略图上传或远程图片。
- 不改变 Page Schema。
- 不实现模板版本上下架后台。

## 责任边界

- 编辑器 playground 负责展示本地模板的可读摘要。
- Template Library Client 继续负责查询模板列表和克隆模板详情。
- Java 配置平台后续可提供更完整的模板元数据，但本任务不实现服务端能力。

## 契约影响

无跨包公开契约影响。本任务只消费现有模板资源字段和 schema 内容，不新增 schema 字段或 npm API。

## 对接说明

后续接入 Java 模板市场时，建议服务端返回标签、版本、节点数、数据源数、动作数和缩略图等摘要字段；当前 playground 可以从 schema 计算这些摘要。

## 验收标准

- 模板卡片展示标签。
- 模板卡片展示版本。
- 模板卡片展示节点数、数据源数和动作数摘要。
- 搜索模板时标签仍可作为匹配依据。
- 应用模板流程不受影响。
- `pnpm typecheck` 通过。
- `pnpm build` 通过。
- `pnpm test` 通过。
- `pnpm smoke:browser` 通过。

- 模板搜索和一键应用流程保持不变。
