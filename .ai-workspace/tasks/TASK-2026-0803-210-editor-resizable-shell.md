# TASK-2026-0803-210-editor-resizable-shell

## 状态

verified

## 目标

继续优化 Vue3 编辑器 playground 的工作区布局，让下方编辑内容区具备左右面板展开/收缩、拖拽调宽、画布拖拽、结构浮层拖拽，以及右侧属性/数据源优先的操作路径。

## 背景

上一轮已把左侧改为物料/模板 Tab、结构树迁移到画布右下浮层、画布扩展设备预设并让右侧属性优先。用户进一步要求：顶部 header 暂不变；下方左中右区域中，左右两侧需要可展开收缩并能拖动边界设置宽度；中间模拟手机区域和结构浮层均可拖动；点击画布节点或左侧物料时，结构和右侧属性/数据源应跟随定位；右侧不应展示 H5 预览入口、交付清单、发布审核、发布检查、本地版本等流程信息，这些应收回到 header 入口，点击后再展示。

## 涉及包或系统

- `apps/editor-playground`
- 文档与 AI 工作流

## 范围

包含：

- 左右面板支持折叠、展开和边界拖拽调宽。
- 中间画布手机区域支持拖拽平移。
- 结构浮层支持拖拽移动，并保留展开/收起。
- 选中画布节点、结构节点或添加物料后，右侧自动聚焦属性/数据编辑，结构树滚动到对应节点。
- 右侧仅保留属性和数据相关编辑入口。
- H5 预览入口、交付清单、发布审核、发布检查、本地版本通过顶部流程入口触发浮层展示。
- 更新 smoke check、AI 记忆和任务验证记录。

## 不包含

- 不修改 Page Schema v1 或 Material Manifest v1。
- 不修改 renderer、runtime、materials 行为。
- 不接真实 Java 配置平台。
- 不实现完整生产级布局持久化、多人布局偏好同步或复杂窗口管理。

## 责任边界

当前仓库：

- Vue3 editor playground 负责演示可迁移到管理台的工作台交互。
- 顶部流程入口、左右栏尺寸、结构浮层位置和画布平移状态仍属于 playground shell 状态。

外部系统：

- Java 管理台后续负责真实权限、协作、审批、布局偏好持久化和服务端发布流程。
