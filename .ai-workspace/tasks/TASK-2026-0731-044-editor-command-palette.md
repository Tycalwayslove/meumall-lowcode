# TASK-2026-0731-044 编辑器快捷命令面板

## 状态

verified

## 目标

为 Vue3 编辑器 playground 新增全局快捷命令面板，让运营人员可以通过搜索快速执行常用操作、应用模板、添加物料和切换编辑模式，提升页面搭建效率和可发现性。

## 背景

当前编辑器已具备物料搜索、模板筛选、属性面板分组、资源选择器和发布检查，但常用操作仍分散在左侧、顶部和右侧面板。运营人员在高频搭建活动页时，需要更快的“搜索即操作”入口，减少来回找按钮和面板的成本。

## 涉及包或系统

- `apps/editor-playground`
- `scripts/browser-smoke.mjs`
- `.ai/PROJECT_STATE.md`
- `.ai/AI_CONTEXT.md`
- `.ai/TODO.md`

## 范围

- 新增编辑器全局快捷命令面板。
- 支持搜索并执行：切换设计/预览/源码模式、保存草稿、生成预览、发布页面、打开 React H5 预览、清空画布。
- 支持搜索并添加当前物料库物料。
- 支持搜索并应用页面模板。
- 支持键盘快捷键打开/关闭命令面板。
- 补充 browser smoke check 覆盖命令面板入口、搜索和基础执行。
- 更新 AI 项目状态和 TODO。

## 不包含

- 不引入第三方命令面板依赖。
- 不实现权限控制、操作审计或服务端命令配置。
- 不修改 Page Schema、Material Manifest 或 renderer API。
- 不替代已有顶部按钮、左侧模板/物料入口和右侧属性面板。

## 责任边界

- Vue3 编辑器 playground 负责 UI、命令聚合和操作触发。
- `packages/editor` 暂不承载 UI 命令面板，后续正式管理台组件化时再下沉可复用逻辑。
- browser smoke 只验证核心路径可用，不覆盖全部命令组合。

## 契约影响

- 不改变 schema、manifest、renderer 或 adapters 公开契约。
- 属于编辑器 playground 体验增强，对已发布页面无兼容风险。

## 对接说明

后续迁入管理系统时，可以把命令项拆成“命令注册表”，由管理台根据权限、页面状态和物料市场动态注入。本任务先在 playground 内聚合现有能力。

## 实现记录

- Vue3 编辑器顶部新增“命令”入口。
- 新增全局快捷命令面板，支持搜索常用操作、视图模式、物料和模板。
- `Meta/Ctrl + K` 可打开/关闭命令面板，`Escape` 可关闭，`Enter` 可执行首个可用命令。
- 命令面板支持添加物料、应用模板、设计/预览/源码模式切换、保存草稿、生成预览、发布页面、打开 H5/React H5 和清空画布。
- 清空画布会保留页面配置并移除所有节点，同时清理选中态和多选态。
- browser smoke 已覆盖命令面板打开、搜索商品榜单物料、执行添加、模式切换和保存草稿。
